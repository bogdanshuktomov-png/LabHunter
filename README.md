## What is LabHunter?

**LabHunter** is a lightweight desktop overlay built for **Path of Exile 1 (PoE 1) Labyrinth runners** farming **Transfigured Gems**. Instead of alt-tabbing to check **poe.ninja** or manually looking up routes on **poelab**, LabHunter recognizes the 3 gems inside the **Divine Font** in one keypress (`F9`), shows live Chaos/Divine values directly over the game, and guides you through daily Lab layouts with a built-in **Lab Compass**.

## Quick Start

1. Download **`LabHunter.exe`** from the **[Latest Release](https://github.com/bogdanshuktomov-png/labhunter/releases/latest)**.
2. Run `LabHunter.exe` on Windows 10/11.
   > *Note: Because the app is an indie PyInstaller build without a paid code-signing certificate, Windows SmartScreen may show a warning on first launch — click **More info → Run anyway**.*
3. Open the **License** tab and start your **1-Hour Free Trial**.
4. Press **`F9`** at the Divine Font in Path of Exile to scan and price-check the offered transfigured gems.

- Verified out of the box on **1080p (`1920x1080`)** monitors.
